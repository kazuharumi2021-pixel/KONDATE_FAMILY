# きょう何にする？
家族向け献立PWA。GitHub Pagesでそのまま公開できます。

## 公開
1. このフォルダ内の全ファイルをGitHubリポジトリ直下へアップロード
2. Settings > Pages > Deploy from a branch
3. Branch を main、Folder を /(root) にして Save

## 主な機能
週間提案、1食相談、材料・手順、お手伝い、買い物集計、作った履歴、栄養分析（一食・今日・今週・今月・今年）、バックアップ/復元。

## 注意
データは端末のブラウザ内に保存されます。別端末とは自動共有されません。栄養値はレシピ登録値による概算です。
